# Imágenes de referencia de la marca

Son las láminas que se usaron para decidir la marca. **No son la fuente de verdad:** la marca se construye con el código SVG de la sección 3 de `../GUIA-GRAFICA.pdf`. No se recortan, no se vectorizan ni se copian a mano desde estas imágenes.

- `logotipo-definitivo.png`: logotipo «norka», versiones y construcción.
- `isotipos-ronda-3.png` y `isotipos-ronda-4.png`: rondas de isotipos exploradas. La elegida es «Órbita» (ronda 4, propuesta 6).
